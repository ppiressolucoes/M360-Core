# M360 Core v0.7.4.0.69

## Barra de navegação unificada

Novo shortcode:

```text
[m360_header_navigation menu_en="EL360 Menu Principal en-US"]
```

O componente reúne menu, seletor de idioma e busca em uma única barra. O layout usa 80/10/10 em desktop/tablet e 33/33/33 no mobile. A fixação durante a rolagem ocorre sobre o conjunto inteiro.
