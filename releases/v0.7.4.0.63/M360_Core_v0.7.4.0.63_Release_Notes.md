# M360 Core v0.7.4.0.63

## Ajustes da validação en-US do Portal Energia Limpa

- Etiquetas de categoria dos blocos editoriais usam texto branco sobre a cor primária.
- Botão de voltar ao topo e seletor de idioma usam a cor secundária, com hover na primária.
- Submenus mantêm texto branco no estado normal, foco e hover.
- Seletor de idioma recebeu fallback visual de bandeira por CSS para ambientes sem emoji colorido.
- Navegação e paleta são enfileiradas no preview/editor do Elementor para permitir ajuste de margens no Theme Builder.

## Compatibilidade

- Mantém shortcodes existentes, Polylang, pt-BR/en-US e o comportamento híbrido do PEL.
- Não ativa takeover da Home automaticamente.
