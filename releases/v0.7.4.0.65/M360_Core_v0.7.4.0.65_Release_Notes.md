# M360 Core v0.7.4.0.65

## Validação visual PEL

- Bandeiras PT/EN renderizadas por SVG inline, sem deformação ou dependência de fonte emoji.
- Seletor de idioma alinhado a 54px, sem margem vertical introduzida pelo shortcode.
- Shell de navegação neutraliza margem/padding próprios para respeitar o espaçamento configurado no Elementor.
- Botão de topo utiliza diretamente `--m360-secondary` e hover em `--m360-primary`.
- Último separador dos itens mini é removido com prioridade para evitar linhas duplas.
