# M360 - Core Editorial v0.7.4.0.29

- apresenta o botão de voltar ao topo em formato quadrado com bordas arredondadas;
- suaviza a rolagem e as transições de exibição e ocultação;
- mantém acessibilidade para teclado e preferência por redução de movimento;
- renderiza automaticamente o seletor de idioma gerenciado pelo Core e pelo Polylang;
- evita duplicidade quando o shortcode `[m360_language_switcher]` ou um botão legado ainda estiver presente.

Os scripts manuais de voltar ao topo e de troca de idioma podem ser removidos dos modelos do Elementor.
