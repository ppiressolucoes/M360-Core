# M360 - Core Editorial v0.7.4.0.26

- permite administrar os modelos editoriais por idioma e por qualquer categoria do portal;
- mantém o shortcode `[m360_editorial_widget id="..."]` estável quando a configuração do bloco é alterada;
- usa o idioma padrão do site nas novas instâncias e, com Polylang, mostra as categorias do idioma selecionado;
- restaura o menu `M360 Core` e seus submenus operacionais;
- preserva as correções de identificação do plugin e do play/pause do ticker entregues na versão anterior.

## Uso no Home Center PT-BR

1. Acesse **M360 Core > Editorial**.
2. Crie uma nova instância, escolha o idioma **Português (pt-BR)**, o modelo e uma ou mais editorias.
3. Publique o shortcode estável exibido na lista, por exemplo `[m360_editorial_widget id="destaque-home-pt"]`.
4. Para trocar Flamengo por outra editoria, edite a mesma instância e salve. A página que contém o shortcode não precisa ser alterada.

Quando o idioma de um widget existente for trocado, salve a alteração e reabra o formulário antes de escolher as categorias do novo idioma.
