# M360 Core v0.7.4.0.67

## Correção da validação v0.74.0.66

- Sticky passa a ser aplicado ao próprio shell `m360-navigation-shell.m360-ui-nav`.
- O placeholder do sticky é calculado pelo JavaScript para manter o fluxo da página.
- Widget Elementor que contém a navegação não adiciona margem, padding ou altura mínima.
- Bordas inferiores residuais dos artigos do Newsroom são removidas.
- SVG do botão flutuante de idioma recebe dimensões e visibilidade obrigatórias.
