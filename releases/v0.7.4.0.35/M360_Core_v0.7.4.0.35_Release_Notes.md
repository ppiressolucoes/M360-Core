# M360 Core v0.7.4.0.35

## Menu institucional

O menu interno das páginas institucionais passa a usar uma única coluna também no desktop. Cada botão ocupa a largura disponível e mantém o texto em uma linha, evitando que nomes longos sejam quebrados ou embaralhados.

O layout mobile permanece em coluna única, com o alinhamento e o espaçamento da validação anterior.
